# JTTest6 - Customer Boolean Field Extension

**Date:** 2026-04-02
**Status:** COMPLETE

## What was built
- App name: JTTest6 (ID: a8f4e7d3-5c2b-4f1a-9e6d-3b8c7a4f2d1e)
- Container: JTTest5 (shared container)
- Adds "Hermes is the Best" (Boolean) to Customer table (field 50100)
- Shows on Customer Card and Customer List pages
- Version: 1.0.0.0, installed on default tenant

## AL Source Files (in JTTest5 container at C:/Run/my/)
1. CustomerTextExt.al — tableextension 50100 on Customer, field 50100 Boolean
2. CustomerCardExt.al — pageextension 50101 on Customer Card
3. CustomerListExt.al — pageextension 50102 on Customer List

## Key lesson learned
- JTTest5 used pageextension IDs 50101/50102 → JTTest6 also needs 50101/50102 → CONFLICT on publish
- Fix: Uninstall JTTest5 before installing JTTest6 (or use non-overlapping IDs)
- alc.exe at C:/Run/alcwork/alc.exe (was 0 bytes previously, now extracted and working)
- CustomerListExt: "Address" field doesn't exist in "Customer List" → use "Name" instead
